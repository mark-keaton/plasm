# Starter

A booking service for shared equipment: an F# domain and its data access on Plasm (`src/Starter.Data`), called by a C# minimal API (`src/Starter.Api`) through one type, `BookingData`, and tested in a sandbox whose changes are rolled back (`tests/Starter.Tests`).

- **Packages:** Plasm.Postgres comes from nuget.org at the version `Directory.Packages.props` names; `dotnet restore` fetches it with Plasm and Plasm.Annotations.
- **Run:** create a database and its tables, `createdb starter && dotnet run --project src/Starter.Api -- ddl | psql -d starter`, then `ConnectionStrings__Starter="Host=localhost;Database=starter;Username=...;Password=..." dotnet run --project src/Starter.Api --urls http://localhost:5080`. Without PostgreSQL on the machine, run it in Docker: `docker run -d --name starter-db -e POSTGRES_PASSWORD=starter -e POSTGRES_DB=starter -p 5432:5432 postgres:18`, then `dotnet run --project src/Starter.Api -- ddl | docker exec -i starter-db psql -U postgres -d starter`, and the connection string `Host=localhost;Database=starter;Username=postgres;Password=starter`. Add `LogSql=true` to print each command Plasm sends, and `ClockStart=2030-01-02T09:00:00Z` to start the API's clock at that instant (it runs on from there; unset, it is the system's), to see a rule about time over HTTP.
- **Test:** `dotnet test` (Docker starts a PostgreSQL for the run).
- **Publish natively:** `dotnet publish src/Starter.Api -r linux-arm64` (or your RID), then `ConnectionStrings__Starter="..." ClockStart=2030-01-02T09:00:00Z src/Starter.Api/bin/Release/net11.0/linux-arm64/publish/Starter.Api`. The tests publish and run the same way: `dotnet publish tests/Starter.Tests -r linux-arm64`, then `tests/Starter.Tests/bin/Release/net11.0/linux-arm64/publish/Starter.Tests`. Two IL warnings are expected, FSharp.Core's IL2104 and IL3053; any other `warning IL` is a problem. On macOS the linker's `dsymutil` also prints warnings about duplicate debug map objects and a missing `.pcm`: they concern the `.dSYM` debug symbols only.
- **Make it yours:** replace `Domain.fs` with your records and rules, and `BookingData.fs`'s methods (and its `BookingUnavailableException`) with what your API calls; the C# side changes only where those do. The names that say Starter are the solution (`Starter.slnx`), the projects and their namespaces (`Starter.Data`, `Starter.Api`, `Starter.Tests`), the JSON context `StarterJson` and the connection string `Starter`; `dotnet new plasm-api -n YourName` gives them your name, and in a copy you rename them yourself.
- **Answers:** a value its `create` refuses (`EquipmentName`) answers 400 with the field; a request whose JSON has a property null or missing answers 400 with an empty body, from ASP.NET's binding, before BookingData is called; a refusal of the rules answers 422; a stale copy 409.
