features/cancellation.feature	On a rollback-journal file, a commit waiting for a reader is cancelled by its token	a rollback-journal file: PostgreSQL has no journal mode, and its commits never wait for readers
features/array-columns.feature	A double that is not a number cannot be stored in a list on SQLite	SQLite stores a list as JSON, which has no NaN or infinity; PostgreSQL's float8[] holds them (differences.txt)
features/array-columns.feature	A list column holding what is not a JSON array is a read error naming the column	SQLite's TEXT can hold what another tool wrote; PostgreSQL's array column holds only arrays of its type
features/array-columns.feature	A list element of the wrong type is a read error naming the column and the element	SQLite's JSON can hold an element of any type; PostgreSQL's array holds only its element type
features/utc-only.feature	A time column holds one form, held to it by its check, on SQLite	SQLite's TEXT can hold any text; PostgreSQL's timestamptz holds only instants
features/utc-only.feature	A time column holding another form is a read error naming the column, on SQLite	SQLite's TEXT can hold what another tool wrote past the check; PostgreSQL's timestamptz holds only instants
features/array-columns.feature	A double that is not a number cannot be stored in its own column on SQLite	Microsoft.Data.Sqlite cannot store NaN; PostgreSQL's float8 holds it
features/array-columns.feature	A query among doubles one of which is not a number is refused on SQLite	SQLite cannot compare with NaN, as it cannot store one; PostgreSQL's float8 holds it
features/providers.feature	SQLite's exact window sum and average follow a frame that rows leave and that empties	Plasm.Sqlite's own window functions called directly, by a frame Plasm's queries do not write; PostgreSQL's SUM and AVG over numeric are its own
features/providers.feature	A value SQLite's exact window sum cannot read fails its query, and the connection goes on	SQLite's decimals are text another tool may have written; PostgreSQL's numeric holds only numbers
features/constraints.feature	On SQLite a unique index or foreign key under another name holds its field	SQLite names no unique index or foreign key in a violation, so one of another name still holds its field; PostgreSQL maps a violation by the constraint's name, and reports a misnamed one (its @postgres scenarios)
features/constraints.feature	On SQLite a duplicate under a unique index of another name is the field's error	SQLite gives a unique violation's table and columns, not the index's name; PostgreSQL names the index, which the schema check reports misnamed
features/constraints.feature	On SQLite a reference to a missing row under a foreign key of another name is the field's error	Plasm.Sqlite finds the broken foreign key by its table and columns (ForeignKeys); PostgreSQL names the key, which the schema check reports misnamed
features/constraints.feature	On SQLite a foreign key failure in a database with triggers stays unnamed	Plasm.Sqlite finds a foreign key's columns by running the statement again, which triggers would see twice; PostgreSQL names the key, with or without triggers
