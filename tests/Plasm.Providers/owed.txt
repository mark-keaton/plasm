# What the SQLite provider owes before it is called whole (docs/status.md),
# each with where it is decided. Plasm.Sqlite is not packed until this list is
# empty and the SQLite run covers every feature file (sqlite-run.sh says how
# many it covers).
A linear window SUM and AVG of decimals: the JSON form is quadratic (6 s over 10,000 rows). Decided: a true window function (sqlite3_create_window_function through our own P/Invoke, callbacks from Marshal.GetFunctionPointerForDelegate<T>), checked on Linux arm64 and x64, runtime and native, one library version from the driver and the import. Scenarios on both databases for a moving frame, AVG and a frame that empties (NULL); the native check gives a failing callback's DbError, the connection working after it, no state left after a failed and a cancelled query, and a 100,000-row running sum timed. The one function serves the plain aggregate too, and the JSON form and plasm_decimal_json_sum are deleted
Lists of scalars as JSON text (the two array-column dialect members): until then refused on SQLite (ArrayColumns false), their scenarios tagged @postgres
JSON documents ([<Json>] fields) through a SQLite JSON dialect: until then refused (Json None), their scenarios tagged @postgres
An enum stored as text with a CHECK in the DDL, compared by the schema check (CHECKs from sqlite_schema, normalised)
Snapshot and Chaos isolation reported as UnsupportedByProvider, not raised
The two-writer scenario: a second writer waits at BEGIN IMMEDIATE, then proceeds, or fails when SqliteOptions.BusyTimeout passes
Every feature file on SQLite: brought on one by one (sqlite-features.txt)
The measurements taken again on an idle machine before the docs give them (ordering and summing 100,000 decimals against integers; the window sum)
The SQLite docs: the caller's thread, the escape hatch (Sqlite.connectionOf) and what it gives up, journal modes and their waits, the differences (differences.txt)
The package check's assertion that Plasm.Sqlite packs to nothing, taken out in the commit that calls the provider whole
