The Plasm Koans in a terminal

The same koans run on your machine with the .NET SDK and Docker (or a PostgreSQL server):

git clone <the Plasm repository>
cd plasm
dotnet run --project koans/Plasm.Koans

Fill in each blank (__) in koans/Plasm.Koans/Lessons and run the command again. Set PLASM_KOANS_PG to an admin connection string to use your own PostgreSQL server instead of Docker.
