Use Plasm (https://mark-keaton.github.io/plasm) to build a library lending desk over PostgreSQL: members borrow and return copies of books. The host is a C# ASP.NET minimal API, the domain and its persistence are an F# project it references, and it is published with native AOT.

Start from the template; do not start from nothing:
- Run dotnet new install Plasm.Templates, then dotnet new plasm-api -n Lending, in a folder reached by its real path: on macOS /tmp and /var are symlinks, and NuGet drops packages through one.
- Run dotnet test before you change anything. It needs Docker, and it must be green first.
- PostgreSQL for the running host can come from Docker too: postgres:18.
- If I ask for SQLite instead, add --database sqlite to dotnet new plasm-api: the database is a file with no server, dotnet test needs no Docker, and in Development the host makes the file at start.
- Read https://mark-keaton.github.io/plasm/llms-full.txt, every docs page in one file. Read the start pages, the guide and "A C# host over an F# domain"; the rest can wait. Where the site and the packages you installed differ, the packages are right: the site can describe a newer version.

Then replace its booking domain with this one:
- A member borrows a copy if they hold fewer than three loans and the copy is not out.
- A loan is due in 21 days. Returning it late records a fine.
- A change made from a stale version of a record is refused, never merged.

Keep everything else the template gave you, and write none of it again:
- Its project files, nuget.config, global.json and JSON serializer options stay as they are.
- C# sees one F# type: plain arguments in, a Task of a union out. C# writes no query and switches over each outcome with no default arm.
- Records carry [<Table>], an id is a single-case type, a validated value has a create function. Write no mapping.
- Every write is a Tx step, and a caller's copy is read with Tx.oneAsSeen. Time comes from the TimeProvider, never from the system clock.
- Every test runs inside SandboxAsync against a real PostgreSQL. Mock nothing.

You are done when:
- dotnet test is green.
- The host starts with Plasm's start-up check on, which is the default.
- A request with a null or missing property answers 400.
- dotnet publish prints no IL warning other than FSharp.Core's two, IL2104 and IL3053.
- You have borrowed and returned a book over HTTP against the native binary.

Then leave it running and show me the requests as curl commands I can run, with the SQL Plasm sent for each, which LogSql=true prints.
